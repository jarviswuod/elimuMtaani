# RISKS.md — elimuMtaani

Format: RISK-NNN — risk — likelihood/impact — mitigation. Highest-attention for Sprint 001: **RISK-003, RISK-005, RISK-006, RISK-007**.

| ID | Risk | L/I | Mitigation |
|---|---|---|---|
| RISK-001 | **API cost / latency blowup.** Naive design generates a lecture for every timetable day upfront (40 days × multi-call pipeline) — slow, expensive, wasted. | M / H | Timetable generation is ONE structured-output call. Lectures generate **lazily** — only when a day is opened — and are persisted, so a repeat open costs nothing. Quiz grading uses `claude-haiku-4-5` (DEC-008). |
| RISK-002 | **Hackathon time overrun / scope creep.** Six features, 3 hours. | H / H | Checkpointed build (handoff-prompt.md): each checkpoint is independently demoable. **Cut order if behind:** Magpie TTS (keep SpeechSynthesis) → YouTube transcript → KICD scrape (keep pasted text) → leaderboard → student review view → chat. Never cut: student open-topic lecture, teacher timetable, day→lecture delivery. |
| RISK-003 | **Magpie TTS Zeroshot contract unknown** (Q-001): auth, request shape, latency, streaming vs file, pricing all unverified. | H / M | Not on the critical path: Checkpoints 1–3 ship with browser `SpeechSynthesis` narration. Magpie is a Checkpoint-4 swap behind a single `synthesize(text) → audioRef` interface in `convex/tts.ts`. Pre-generate demo audio as fixture files if the contract resolves late. |
| RISK-004 | **Clerk + Convex auth wiring friction.** Role-gated routes across two managed services, configured under time pressure. | M / M | Use the official Clerk+Convex integration template verbatim at Checkpoint 1; role lives in a single `users` table keyed by `clerkId`; middleware does route-group gating (`/teacher/*`, `/student/*`) only — no per-resource ACLs this sprint. |
| RISK-005 | **Three research integrations in one sprint** (KICD scrape/PDF parse, YouTube transcript, pasted text). | H / H | Pasted text is the guaranteed, demo-critical path (DEC-004). KICD scrape and YouTube are stretch, each behind the same `ResearchSource.extractedText` interface so cutting them changes nothing downstream. |
| RISK-006 | **Timetable structured-output shape.** A term timetable (weeks → days → topics) is a deep nested object; the model may return malformed/unbalanced weeks, wrong day counts, or drift from the research source. | M / H | Zod schema with hard bounds (weeks 1–13, days 1–5, topic string lengths); structured-output API retries on schema mismatch; deterministic post-validation (pad/trim weeks) so the UI never renders a ragged grid; research text included in the prompt with instruction to ground topics in it. |
| RISK-007 | **Two renderers, one data model.** Teacher live delivery and student read-only review both render `Lecture.slides`; divergence means double maintenance or broken review views. | M / M | One `<SlidePlayer>` component with a `mode: 'live' \| 'review'` prop; review mode disables chat/regenerate/narration-controls but reads the identical record. Slides JSON is the single contract — schema frozen in blueprint.md. |
| RISK-008 | **Model ID / API misconfiguration invisible under fixtures.** (Session-observed: a prior scaffold shipped nonexistent `claude-opus-5`.) | M / H | DEC-008 pins verified IDs; acceptance.md includes one mandatory real-API smoke test with fixtures OFF before the demo. |
| RISK-009 | **A freshly generated game may be unplayable in a real room** — 40–60 learners, zero extra materials, one teacher. Nothing in the generation flow can verify playability. | M / H | Library-first (DEC-015) makes generation the rare path; strict schema + materials allowlist (DEC-016) catches the mechanical failures; a teacher-review flag on every generated game (`teacherReviewed`) + post-game worked/didn't-work rating routes real-classroom feedback back into the library (Q-006). "AI-designed — review before class" badge sets expectations. |
| RISK-010 | **The understanding gate can stall a term** — a strict gate + a struggling class means the timetable falls behind and teachers abandon the loop. | M / M | The gate is advisory, never enforcing (DEC-017): the teacher can always advance or skip; Sprint 001's merge-into-next-day remains the escape hatch; strictness is her stored preference (US-27), displayed not imposed. |
| RISK-011 | **A worksheet wearing a game label slips through** — the model returns "discuss in groups" shaped output that technically fills the schema. | M / M | `mechanics` fields required non-empty + the acceptance **worksheet test** (adversarial topic phrasing) + few-shot contrast table in the prompt (the doc's not-this/this table verbatim). |
